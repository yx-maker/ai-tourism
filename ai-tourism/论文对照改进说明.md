## 三、核心功能模块（对照开题报告"四、核心研究内容"）

### ① 用户管理模块（核心）✅
- 注册、登录、JWT 鉴权（Sa-Token，短期 token + refresh token）、修改密码、用户信息管理
- 角色权限体系：USER / ROOT 双角色，注解式权限控制
- 新增：禁用用户、ROOT 授权接口（原有，开题报告"用户管理"完整覆盖）

### ② AI 路线规划模块（核心，最重要）✅
- 自然语言输入（如"西安4日游，预算4000，喜欢历史古迹"）→ LLM 生成结构化行程
- **SSE 流式输出**：文字攻略逐字渲染 + 结构化路线 JSON 并行生成
- AI 问答功能：复用同一 LLM 接口 + Prompt 体系（开题报告的创新点4）
- **多轮对话记忆**：Redis 短期记忆 + MySQL 历史回填 + 会话级实例隔离（Caffeine 缓存）
- **工具调用**：POI 景点检索工具（查 MySQL 真实景点）+ 天气工具（Open-Meteo 免费接口）

### ③ 景点管理模块（核心）✅【本次新增】
- 后台 CRUD：新增 / 修改 / 删除 / 分页查询 / 关键词搜索 / 城市筛选
- 景点字段：名称、城市、描述、经纬度、城市排名、全国排名、**门票价格**（本次新增字段）
- 权限：ROOT 角色持有 `poi:manage` 权限
- 数据库：106 个真实景点（24 个城市），门票价格已填充
- 前端：Element Plus 表格 + 分页 + 对话框表单（`/poi-admin`）

### ④ 地图可视化模块（核心）✅
- 高德地图（AMap JS API）+ OpenStreetMap（Leaflet）双地图服务，可切换
- 默认 OSM（免 key 开箱即用），配置 `VITE_AMAP_API_KEY` 后可切回高德
- 路线展示：每日路线点位标记 + 驾车/步行路线规划 + 卫星图/底图切换 + 适应路线

### ⑤ 预算分析模块（核心）✅【本次新增】
- **双引擎架构（论文创新点）**：
  - 引擎一（LLM 结构化提取）：行程生成后，调用大模型按 JSON 模式输出交通/住宿/餐饮/门票/其他五类分项与总预算
  - 引擎二（规则兜底）：LLM 失败时按行业均价估算（平均门票×景点数、住宿×晚数、餐饮×天数…）
  - 融合策略：LLM 优先、缺失字段规则补全，保证输出稳定可解析（回应开题报告"核心难点"）
- 自动触发：AI 对话完成后台异步分析并落库（不阻塞主流程）
- 前端：ECharts 饼图（分项占比）+ 柱状图（分项对比）+ 六项统计卡片（`/budget`）
- 实测：西安4日游自动分析 总预算3870 = 交通640+住宿750+餐饮480+门票1600+其他400

# DESIGN.md — 旅途前端设计系统

> 本文件记录**已经落地的视觉决策**，不是设计提案。改样式前先读这里，改完同步更新。
> 实现入口：`src/styles/theme.css`（令牌 + 基础）、`src/styles/ui.css`（组件类）、
> `src/styles/markdown.css`（对话正文排版）。

## 一句话

暖白纸面上的近黑墨字 + 一条深青强调色，靠发丝线和大留白分层，不靠阴影和发光。
参照的是大型模型公司产品页的克制感：**内容比装饰重要，排版比质感重要**。

## 方向契约

- **THESIS**：把「AI 生成行程」当成一份可审阅的文件，而不是一张炫技的海报。全站拒绝的类别默认是：深色玻璃拟态、多色渐变、发光描边、工具箱式侧边图标栏。
- **OWN-WORLD**：`#FAF9F5` 纸底、`#FFFFFF` 面板、`#17160F` 墨色、`#E3E0D5` 发丝线、`#0B6B63` 深青。所有层级由 1px 线和灰阶字重完成。
- **STORY**：用户先看到一句主张和一个真实行程片段，相信系统会算账；登录后进入「描述需求 → 读行程 → 看预算 → 存计划」的单一路径。
- **FIRST VIEWPORT**：登录页左侧 60% 是 56px 双行标题 + 一行说明 + 一张带 D1–D3 与预算构成条的行程卡；右侧 360px 是无卡片边框的登录表单，靠 1px 竖线分隔。
- **FORM**：`Product document` 方向（纸张 + 数据排版），不采用仪表盘、不采用终端模拟。
- **FINISH**：unreviewed and undocumented is unfinished；每次改动以截图复查、对比度核对、本文档更新结束。

## 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#FAF9F5` | 页面底、侧栏底、次级分区 |
| `--paper-2` | `#F3F2EC` | 标签底、输入底、轨道 |
| `--paper-3` | `#ECEAE2` | 进度轨道、禁用底 |
| `--surface` | `#FFFFFF` | 面板、卡片、输入框 |
| `--ink` | `#17160F` | 主文字、主按钮底 |
| `--ink-2` | `#454337` | 次要文字 |
| `--ink-3` | `#6B6859` | 三级文字（≥5.3:1） |
| `--ink-4` | `#706C5B` | 元信息（≥4.7:1） |
| `--line` | `#E3E0D5` | 默认发丝线 |
| `--line-strong` | `#CFCABC` | 输入框、可交互边界 |
| `--accent` | `#0B6B63` | 激活态、链接、关键数据、选中块 |
| `--ok` / `--warn` / `--danger` / `--info` | `#14663F` / `#855100` / `#A32B21` / `#1B548C` | 语义色，浅底深字全部 ≥6:1 |

**色彩策略**：Restrained。整站只有一个彩色（深青），且只在「这件事当前有效 / 这是关键数字」时出现。
主按钮是近黑，不是品牌色——行动色和状态色分开，是这套系统最重要的判断。

## 字体

- 拉丁与数字：**Geist Variable**（自托管 `src/assets/fonts/`，不依赖 CDN）。
- 中文：`PingFang SC` → `HarmonyOS Sans SC` → `Microsoft YaHei` 系统栈。
- 等宽：**Geist Mono**，只用于 ID、日期、金额、天数、坐标——数据用它，装饰不用它。

| 层级 | 字号 | 字重 | 字距 |
|---|---|---|---|
| 登录主张 | `clamp(36px, 4vw, 56px)` | 600 | `-0.028em` |
| 页面标题 | `clamp(26px, 2.4vw, 34px)` | 600 | `-0.032em` |
| 面板标题 | 13.5–14.5px | 600 | `-0.012em` |
| 正文 | 13–14.5px | 400 | 0 |
| 数据 | 17–21px | 600 | `-0.03em`，`tabular-nums` |

正文行长控制在 65–75 字符（`.page-head__sub` 为 62ch，对话 780px）。

## 组件规则

- **面板**：白面 + 1px `--line` + 10px 圆角，`padding: 22px 24px`。一层就够，**不再卡中卡**。
- **按钮**：高 38px（移动 44px）、8px 圆角、字号 13.5px。主按钮近黑；次按钮白底描边；`quiet` 无边框。
- **输入**：高 42px、1px `--line-strong`、聚焦时 3px `rgba(11,107,99,.12)` 环。
- **徽标**：22px 高、4px 圆角、11.5px 字号；用色 + 描边成对出现，不用纯色块。
- **导航**：64px 顶栏，左侧品牌、中间文字导航、右侧账号；激活态 = 字重加深 + 2px 深青短线。移动端（≤780px）退化为 40px 图标导航。
- **列表**：行式列表用 `1px --line-faint` 分行，不用卡片网格；卡片网格只用于景点这类天然并列的对象。
- **卡片动作**：轻量动作（收藏、编辑、删除）一律收成 30×30 图标放右上角，**不占一整行**；页脚只放「价格 + 排名/日期」一行数据，上方 `1px --line-faint` 分隔。
- **选择控件（语义决定形状）**：
  - 多选 → 胶囊标签，选中为**深青淡底 + 深青字**（`.chip.is-on`）；
  - 单选项少（2–4 个）→ 一体式分段控件，选中为**深墨实心**（`.seg`）；
  - 单选项多（≥5 个）→ 方格选择 3 列（`.tiles`），选中同样是深墨实心；
  - 同一页不出现三组以上形状相同的胶囊，否则页面立刻变成「标签汤」。
- **Toast**：右下角 `bottom: 22px`、向上堆叠（`column-reverse`），不压顶部导航和面板标题。
- **地图空态**：无坐标点位时占位区 `flex: 1` 吃掉面板剩余高度，点位清单不再占位，避免右侧面板下半部空荡。

## 动效

- 唯一编排过的入口动效是 `.rise`（首屏元素依次上移 8px，最高延迟 0.18s）。
- 过渡统一 `0.18s cubic-bezier(.22,.61,.36,1)`；金额条宽度 0.6s。
- 不使用视差、光晕呼吸、循环装饰动画。
- `prefers-reduced-motion` 下全部降级为 0.001ms。

## 无障碍底线

- 正文与占位符 ≥4.5:1，大字 ≥3:1（色板表内已标）。
- 触控目标 ≥44×44（`pointer: coarse` 下强制）。
- 焦点环 2px 深青 + 2px offset；`skip-link` 常驻；`aria-live` 用于 Toast。
- 原生 `button` / `a` / `input`，不用 `div` + `onclick`。

## 明确禁止

- 渐变文字、玻璃拟态、彩色 `border-left` 装饰条、零偏移彩色光晕。
- 标题上方的 kicker/eyebrow 小标签。
- 同尺寸「图标 + 标题 + 一句话」三卡并列作为页面结构。
- 同一页堆三组以上同形状胶囊标签（单选也用胶囊，是这里最容易犯的错）。
- 卡片底部一整行按钮（收藏/编辑/删除横排），会把信息卡变成工具栏。
- 用 emoji 充当 UI 图标（内容里 AI 生成的表情符号不算）。
- 大数字 + 小标签 + 装饰强调色的 hero-metric 模板。
